What this Worker is for

Pexabo’s production calendar lives at info@pexabo.com (“Pexabo Team”, Europe/London). This app is an edge-native backup + management console: it reads events through the Google Calendar API, stores point-in-time snapshots in Cloudflare KV, and exposes the same operations as REST and as MCP JSON-RPC so an agent (or curl) can drive it.

Why backup calendar events?

  • Google Calendar is the system of record — it is not a durable archive.
  • Recurring series, deletions, and ACL changes can hide history.
  • A KV snapshot is a portable JSON + ICS copy you can grep, restore, or hand to an agent.
  • The Worker runs next to the user on 300+ Cloudflare cities — no always-on VM.

What a snapshot contains

  • Event id, iCal UID, status, start/end, timezone, htmlLink, visibility, updated time.
  • Summary, description, location, attendees — when the service account is a reader or writer.
  • Today the shared ACL is freeBusyReader, so titles render as Busy. Upgrade sharing on the Permissions page to unlock details.
  • ICS download at /api/backups/<id>.ics.

Two control planes, one Worker

Every mutating action on the Push page is just a fetch against these contracts. Use whichever your agent prefers.

REST API

MethodPathPurpose
GET/api/healthEdge diagnostics (colo, country, runtime)
GET/api/calendarCalendar metadata + current accessRole
GET/api/eventsList events (timeMin, timeMax, maxResults)
POST/api/eventsCreate event (writer ACL)
GET/PATCH/DELETE/api/events/:idRead / update / delete one event
POST/api/backupSnapshot the window into KV
GET/api/backupsIndex of snapshots
GET/api/backups/:idFull JSON snapshot
GET/api/backups/:id.icsICS export
POST/api/backups/:id/restoreRe-create events (writer ACL)
 
curl -s https://HOST/api/events | jq '.items | length'
curl -s -X POST https://HOST/api/backup \
  -H 'content-type: application/json' \
  -d '{"timeMin":"2026-08-22T00:00:00Z","timeMax":"2026-09-05T00:00:00Z"}'

MCP JSON-RPC

POST /mcp with JSON-RPC 2.0. Compatible with MCP initialize, tools/list, and tools/call. Tools can also be invoked directly as method names.

ToolDoes
calendar_statusACL, timezone, service account email
calendar_list_eventsList the Pexabo Team calendar
calendar_get_eventFetch one event by id
calendar_create_eventInsert (needs writer)
calendar_update_eventPatch (needs writer)
calendar_delete_eventDelete (needs writer)
calendar_backupWrite a KV snapshot, return backup id
calendar_list_backupsIndex
calendar_get_backupFull snapshot
calendar_restore_backupReplay events onto the calendar
 
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "calendar_backup",
    "arguments": { "timeMin": "2026-08-22T00:00:00Z", "timeMax": "2026-09-05T00:00:00Z" }
  }
}

Discover tools: GET /mcp or POST /mcp with {"method":"tools/list"}. The Push page Command studio can fire both REST and MCP without leaving the browser.

Cost

Designed to stay on the Cloudflare Workers Free plan: 100,000 requests/day, $0/month. KV writes are 1,000/day on free tier — plenty for a handful of daily snapshots. Azure Key Vault is only touched at deploy time (~$0.03 / 10k operations).
